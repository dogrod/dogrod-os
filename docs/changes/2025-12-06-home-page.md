# Home Page - Personal Card Design

**Date:** December 6, 2025

This changelog documents the creation of a new minimalistic home page for dogrodOS, designed as a casual personal card page.

---

## 1. New Home Page

### Files Changed
- `app/page.tsx` (replaced)

### Design Concept
- **Single-screen personal card** - fits in one viewport on laptops
- **Minimalist monochrome palette** - white, light gray, dark gray only
- **Content balance** - approximately 50% life, 50% work

### Structure
1. **Hero Section** (two columns on desktop)
   - Left: Title "Hi there!" with intro text
   - Right: Profile image from CDN
2. **About Section** - Two paragraphs covering life and work
3. **Minimal Footer** - Copyright with year

### Styling
- Main content wrapped in a rounded container with padding
- Responsive layout: stacks vertically on mobile, two columns on desktop
- Uses existing design tokens (zinc color palette, Geist fonts)

---

## 2. Page-Local Header Component

### Files Created
- `app/_components/HomeHeader.tsx` (new)

### Features

**Desktop Navigation:**
- Logo with custom image from CDN (`https://cdn.dogrod.com/logo.png`)
- Brand text "Brian Zhu"
- Navigation links: Blog, Gallery
- "Find Me On" dropdown with social links

**Contact Dropdown:**
- Hover-triggered dropdown menu
- Centered positioning below trigger
- Invisible bridge element (padding) to prevent close on mouse travel
- Keyboard accessible (Tab, Escape, Arrow keys)
- Links open in new tab with `rel="noopener noreferrer"`

**Mobile Menu:**
- Hamburger icon toggles vertical menu
- Flat list of all links (no nested dropdown)
- Close on navigation

**Social Links Configured:**
- X (Twitter): `https://x.com/dogrod_`
- Instagram: `https://www.instagram.com/dogrod_/`
- Unsplash: `https://unsplash.com/@dogrod`
- LinkedIn: `https://www.linkedin.com/in/brianzhu7/`

## 8. Accessibility Features

- Semantic HTML: `<header>`, `<main>`, `<nav>`, `<section>`, `<footer>`
- Keyboard navigation for all interactive elements
- `aria-expanded` and `aria-haspopup` on dropdown trigger
- `role="menu"` on dropdown container
- Alt text on all images
- External links use `target="_blank"` with `rel="noopener noreferrer"`
